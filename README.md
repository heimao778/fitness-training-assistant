# 太岁 · 训练助手（原生微信小程序）

个人自用的离线训练记录工具。界面使用原生 WXML / WXSS / JavaScript，不需要后端、网络接口、AI API 或模型密钥。训练进度、逐组记录、常用动作与体重趋势均保存在本机微信存储中。

## 在微信开发者工具中打开

1. 安装并登录最新版[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择「小程序」→「导入项目」，项目目录选择本仓库根目录。
3. 在项目根目录先运行 `npm install`，安装锁定版本的 TDesign 微信小程序组件库。
4. 在微信开发者工具中选择「工具 → 构建 npm」。成功后会按 `project.config.json` 生成 `miniprogram_npm`；不要手工改生成文件。
5. `project.config.json` 默认使用 `touristappid`，可做本地预览；游客模式可能不能真机调试或使用部分能力。
6. 要在手机运行，请在微信公众平台注册小程序并取得测试号或自己的 AppID，然后在开发者工具「详情 → 基本信息」中替换 AppID。不要把密钥写进源码。
7. 点击「编译」。真机调试前，确保当前微信号已是该小程序的开发者/体验成员，再点击「真机调试」或「预览」扫码。

本项目不含发布配置，也不会自动上传或部署。

原生界面使用 `tdesign-miniprogram@1.18.0`，并包含其构建产物直接引用的运行时 helper `tslib@2.9.1`，版本均由 `package-lock.json` 锁定。TDesign 采用 MIT License，tslib 采用 0BSD License；未增加其他依赖。按钮、逐组输入、完成确认弹层、记录列表与设置项使用原生 TDesign 小程序组件。浏览器预览仍是自有 HTML/CSS 适配层，不会运行或模拟 TDesign 组件。

## 在 Linux 本机运行交互预览

官方微信开发者工具不支持 Linux。为方便在 Linux 电脑实际点测，本仓库附带轻量浏览器预览层；它复用同一份 `data/plans.js`、`utils/engine.js` 和 `utils/store.js`，不会替换或改写原生小程序页面。

在项目根目录运行唯一命令：

```bash
npm run preview
```

然后打开：`http://127.0.0.1:4173`

预览服务器只绑定 `127.0.0.1`，不对公网开放，不需要安装依赖、登录或调用外部 API。页面支持部位选择、动作/器械选择、逐组重量与次数、最低休息计时、延长、下一部位、完成循环、休息、记录和设置；刷新浏览器后可从 localStorage 恢复。

`127.0.0.1` 只在运行命令的那台电脑可访问，不是可分享的公网预览链接。本项目没有自动部署；如需从另一台设备点测，应由使用者在可信局域网环境自行调整监听地址和防火墙，或后续选择明确授权的托管方式。本交付不启用公网、付费服务或服务器同步。

页面顶端会持续标明“浏览器预览，非微信运行”。浏览器数据使用 `wechat-preview:` 前缀，与微信 `wx.setStorageSync` 的真实沙箱不是同一份数据。浏览器点测只能验证产品流程与共享纯逻辑，不能证明 WXML/WXSS 已在微信开发者工具编译，也不能替代真机测试。

## 导出手机可打开的单文件 HTML

```bash
npm run export:html
```

输出文件为 `dist/训练助手试用版.html`，内部已包含全部样式、存储适配、训练核心和交互代码，不引用外部文件或网络接口。

给初学者的打开方法：

1. 把 `训练助手试用版.html` 下载到手机文件夹，不要只停留在聊天软件的“附件预览”页。
2. 在手机文件管理中点该文件，选择 Chrome、Edge、小米浏览器等系统浏览器打开。
3. 顶部若显示“记录保存在当前浏览器”，刷新后应能恢复；若显示“临时试用”，说明当前查看器禁止存储，关闭或刷新会丢失记录。
4. 有些聊天附件查看器会完全禁用脚本。此时页面会显示静态中文说明，但不能记录；这不是已保存状态。

开始训练使用明确的按钮点击处理，不依赖查看器可能禁止的原生表单提交。按钮下方的“点了没反应？查看诊断”仅显示执行阶段、存储模式和异常文字，不采集或上传个人数据。

可用 `npm run test:single-html` 自动验证同一文件的 HTTP、`file://`、存储被禁止、CSP opaque-origin 受限沙箱和脚本被禁用五种情况。

## 使用流程

- 首次先选择一套训练分化，之后只在「设置」修改。进入部位后默认只有一行动作配置：先选动作类型，再选该类型已有的器械/具体动作和组数即可开始；“添加另一个动作”完全可选。缺少必填项时会在开始按钮上方直接说明原因。已保存的部位配置会自动恢复，日常训练不必重复填写。
- 训练页一次聚焦一个当前动作；上次同动作没有真实记录时明确显示空状态，不生成示例成绩。
- 每组重量、次数在输入时立即保存，不需要先点「完成」。刷新、退出或返回编辑动作后仍可恢复未完成训练。
- 点「完成」仅确认该组并启动最低休息倒计时；计时结束只提醒，不自动开始或记录下一组。
- 完成本部位后再选下一部位。最终完成会推进循环；休息不推进；跳过需确认且只推进一次。
- 只有明确确认“完成本次训练”才推进循环，重复确认不会重复推进；「保存并结束」只保存部分完成。
- 健身房腿日仅在完成后交替股四/腘绳重点；跳过不切换。居家循环不使用这条交替规则。
- 「记录」独立展示动作历史和训练历史；历史重量、次数可纠错。上次表现只按一致的 kg 单位查找，不跨单位误比。

## 安全边界

默认按“血压仍未确认”显示保守提示：不憋气、不做极限、力竭、HIIT 或 1RM 测试，每组保留约 2–3 次余力。一般疲劳可减量或延长休息；胸痛、明显气促、晕厥等危险症状应停止并及时就医，不继续轻练。本工具不是医疗诊断或医学定制。

训练时间与饭前/饭后的关系只是产品映射，不作为医学限制。应用不鼓励空腹高强度训练、极端热量缺口或按 130 kg 体重乘高蛋白系数。

## 数据与恢复

数据键为 `fitness_coach_v1`，包含 `schemaVersion`、数据版本和校验值。校验失败时会保留一份 `fitness_coach_v1_corrupt_*` 原始副本并恢复安全默认值。清理微信缓存或删除小程序会删除本地记录，当前版本没有云备份。

## 测试

测试覆盖循环完成/休息/换日/跳过、腿日交替、防重复记组、计时后台恢复/调整/延长、进行中循环保护、本地校验恢复，以及浏览器 localStorage 适配与共享核心模块加载：

```bash
npm test
```

预览服务器运行时，如本机已安装 `google-chrome`，可另开终端执行 `npm run preview:smoke`，自动点测默认三分化的一轮、逐组记录、休息延长、循环推进、记录/设置和刷新恢复。

微信开发者工具编译和真机表现仍需在本机工具及真实微信环境中验证；Node 测试不能替代真机验证。
